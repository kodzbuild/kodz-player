# Kodz Player

App IPTV (Xtream Codes) para Android e Android TV, em Kotlin + Jetpack Compose + Media3 (ExoPlayer).

## Build pelo GitHub
1. Envie todos os arquivos para o repositório (branch `main`).
2. Abra a aba **Actions**: o workflow "Build Kodz Player" roda sozinho.
3. Ao terminar, baixe o APK em **Artifacts** (`KodzPlayer-apk`).
4. Para publicar em Releases, crie uma tag, por exemplo `v1.0.0`.
